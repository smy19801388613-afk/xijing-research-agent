# 研序 · 对话投研 Agent v0.4.2

**面向 A 股的可追溯投研与估值智能体。** 主要用于财报分析、研究纠错、估值情景和买方备忘录；量化选股、策略回测与交易执行属于后续扩展。

面向 A 股的本地研究产品。从研究对话出发，由模型选择查公司、取财务数据、检索年报、计算估值或修订报告。财务事实、估值假设、计算结果和研究判断分别保存，保留来源与历史版本。

## v0.4.2：长报告生成与及时停止

- 深度报告使用去重后的原文目录和共享输入预算；DeepSeek 思考调用分配推理与正文的合计预算，长度截断时最多重新生成一次完整 JSON。截断内容不会拼接或写入正式报告，失败用量和原因保留在调用记录中。
- 暂停立即显示正在停止；服务端将本轮标为停止并终止经过进程身份核验的本地任务。已完成步骤保留，可继续提问；旧任务不能写回或覆盖新一轮结果。第三方模型服务是否继续计费由供应商决定。
- 修复自动获取年报时的嵌套数据库写入，并提供更明确的问题状态与引用摘录修订反馈。旧报告只有在新版完整生成并通过现有校验后才更新。

## v0.4.1：从研究问题到报告更新

本版整合 [PR #2](https://github.com/smy19801388613-afk/yanxu-research-agent/pull/2) 的比赛工作区、事实状态与问题级证据，以及 [PR #3](https://github.com/smy19801388613-afk/yanxu-research-agent/pull/3) 的对话约束与原文查证改进，并补充以下体验：

- **管理关键问题**：研究计划聚焦 3–5 项关键问题，优先复用现有清单。问题可设置优先级、编辑完成条件、归档或恢复；归档项不计入当前完成度。修改问题含义会保留原答案和证据，并标记重新核对。规范化去重覆盖空白、标点和大小写，不自动识别所有语义近似问题。
- **完整保留证据**：“记录答案与证据”支持多条支持与反方摘录、缺口和下一步行动。修改答案不会清空已有绑定；草稿收起后可在当前页面继续编辑，尚未保存的草稿不会写入研究记录，也不承诺刷新页面后保留。
- **单独更新报告**：答案、已保存的引用内容或日期变化时，报告提示待同步。点击“通过对话更新报告”会发送使用已有材料更新报告的明确请求，不重新联网、不改变估值参数；成功后保留旧稿。报告生成期间问题或所引来源发生变化时，拒绝将旧输入的草稿标成已同步。旧报告缺少版本关联时如实显示未建立记录。
- **看清本轮执行边界**：聊天展示当前有效约束和明确设置的持续约束。未完成、失败或取消后，展示已完成步骤、剩余事项和报告是否保存；可继续最近一轮未完成研究，复用已保存的成功结果。
- **比赛前先检查材料**：在独立比赛工作区选择材料后，先显示公司、年度、截止日、结构化行的采用/排除情况，以及模型配置和网络许可。预检不请求模型，**已配置且许可不等于连通性、密钥额度或模型质量已经验证**；PDF 可读也不保证自动抽取财务表成功。提交 ZIP 分别保留 JSON/CSV 原始字节与元数据。

问题清单、报告引用和聊天资料覆盖共用证据资格规则：搜索摘要是线索；OCR 与日期未知正文可供明确标注的推断，不能据此将问题标为有充分证据回答；冲突与截止日后的来源有单独限制。事实状态、引用资格、摘录匹配与研究观点分别处理，**这些检查不证明金融语义、因果或投资判断正确**。详见 [v0.4.1 实现与验收记录](docs/acceptance-v0.4.1.md)。

## 在当前电脑使用

新机器先按下方开发说明安装依赖；Windows 在仓库目录运行 `powershell -File scripts/start.ps1`，打开 [研序](http://127.0.0.1:8920/)。启动脚本随仓库提供，不依赖上级目录的个人启动器。

启动窗口显示健康接口返回的真实应用版本、当前入口目录和访问地址；复用已运行服务时也会核对版本。如果端口上仍运行旧版本，会明确报错，请先停止旧服务后重启。访问地址带版本和页面构建标识，页面左上角显示完整应用版本。历史研究的创建版本保留原值。

1. **连接设置**：填写自己的 API Key、服务地址和模型名，保存多套连接，测试或设为默认。首次使用保留原有 DeepSeek / Tushare 配置。
2. **新建研究**：输入公司名称、拼音缩写或代码，选择匹配公司、年度、数据源和材料。也可直接在研究对话里提出公司研究要求。
3. **研究对话**：讨论投资想法、反证、估值方法和缺失资料。每个实际工具动作和结果都会显示。输入区可以直接“上传 PDF”“接入资料”或“查找年报”，新增文件立即可供当前对话检索、按页查阅，无需重建研究。
4. **估值建模**：支持 PE、PS、PB、DCF、EV/EBITDA、DDM。可以自己填写假设，也可先与 Agent 沟通后通过对话计算。
   Agent 可先生成待确认的方案卡片；点击“采用此方案并计算”后才保存估值结果，也可在对话中继续修改方案。
5. **深度研究**：点击“深入研究并保存报告”，或直接要求“联网研究具体产品、最新经营和反方证据，生成并保存备忘录”。Agent 会制定问题、多轮搜索、阅读网页与年报、撰稿、反方审阅、校验引用后保存。公司研究页展示完整报告，旧稿保存在研究版本中。
6. **导出**：Markdown、HTML 默认提供当前报告；完整审计版保留事实、估值情景和修订记录。ZIP 证据包同时包含两者、原始响应、已有 PDF 和文件清单；包内 PDF 引用使用相对路径，解压后可查阅。外部网页仍需联网。HTML 可以打印为 PDF。
7. **删除与恢复**：对话选择框旁可删除当前对话，公司研究页和研究版本列表可删除研究。内容移入侧栏“回收站”，可以恢复；删除研究时关联对话一起移入回收站，资料库原文件保留。运行中的研究或对话需先停止并等其结束。

## 年报与 PDF 查阅

“查找年报”通过巨潮公开披露按公司、年度和研究截止日寻找年度报告全文，下载校验后接入当前对话，**不依赖 Tushare Token**。也可以直接说“找到当前公司的年报全文并查阅”。公开站点不可用时会说明错误，可改用上传入口。

单个 PDF 上限为 **100 MB / 800 页**。系统索引可提取的文字，返回带物理页码的片段和原文链接。遇到扫描页时，按页调用 Windows 本机 OCR 并缓存，标明扫描识别结果；需有本机可用的 OCR 语言包，缺失时返回具体错误。OCR 可能误识别数字或错置表格列，不能直接把它作为已核验财务数值。

上传时选择公司和年度，可补充公告日期；未知公告日的材料可查阅，但不表示满足历史截止日。已有公司年度信息不匹配的文件会被拒绝。新增 PDF 是研究依据，**不会自动覆盖结构化事实或报告**；复杂三表和附注仍需进一步核对。

查阅结果保留原文页码链接。已增加股本金额误写成股数的检查：当可提取文字的表头明确为人民币元、回答把同一个股本余额写成股数且没有对应股份数量依据时，要求模型纠正；重复冲突则返回待核实项。它只覆盖这一类已知错误，不等于通用财务事实审核。

可直接体验：

- “联网查华宇软件具体产品、最新经营、回款和监管信息，审视我的 PS 情景，生成并保存完整买方备忘录。”
- “针对当前公司，比较 PE 和 DCF 的适用性，先不计算。”
- “以已核验利润为基数，下一年增长 10%，PE 15 倍，计算并保存；不填股本。”
- “把 PE 改成 12 倍，其余不变，重新计算。”
- “把报告改为以现金流风险为重点，保留反证与后续核实清单。”

以上参数仅用于演示交互，不是市场预测。停止前先在页面取消正在运行的任务，再运行 `powershell -File scripts/stop.ps1`；独立 Agent 和研究进程不会因关闭浏览器而停止。

## 连接与数据

联网检索使用免密钥的公开财经索引、Bing 与 DuckDuckGo，支持多主题搜索、正文读取和沿官网链接深入查阅；不依赖 Tushare。可选环境变量 `TAVILY_API_KEY` 或 `BRAVE_SEARCH_API_KEY` 接入对应搜索服务。搜索服务会收到搜索词；所选大模型会收到用于分析的公开资料和当前研究上下文。免费来源可能限流或缺少结果，不能保证全网覆盖。

搜索摘要、正文、PDF页、财务事实和用户情景各自保留来源状态、链接与日期。已知晚于截止日的来源排除；日期未知明确标注，不能证明历史时点已知。HTTP与HTTPS跳转不会升级来源可信度，同一消息多处转载不构成交叉核验。

精准查询支持公开披露目录、官方PDF与公告文本镜像；指定 `site:` 的查询严格限制域名，失败不会拿别处结果冒充。`read_public_pdf` 可读取已发现的巨潮、交易所、证监会公告，适用于最新半年报、差错更正和监管文件（12 MB、260页以内，按查询取最多12页，每页最多5000字）。每页保留远程原文页码链接，尚未做OCR；扫描页或超限会明确失败。公告独立保存为研究来源，不擅自替换当前年度底稿。

| 类型 | 已实现 |
|---|---|
| 模型预设 | DeepSeek、OpenAI、通义千问、Anthropic、Ollama、自定义兼容接口 |
| 模型协议 | OpenAI 兼容 Chat Completions、Anthropic Messages；模型名和地址均可编辑 |
| 财务来源 | Tushare Pro、东方财富公开年度财务、仅使用已上传披露文件 |
| 年报全文 | 巨潮公开披露自动查找下载，或聊天上传 / 接入资料库 |
| 公司目录 | Tushare 在市 A 股主表，每日缓存，支持名称、拼音缩写、代码匹配及近似名称搜索 |
| 无 Token 时 | 已存公司目录仍可搜索；无缓存时提供本机历史目录，可手动输入完整代码 |
| 无模型密钥时 | 样例回放、文件研究、取数、确定性计算仍可使用；对话需要可用模型或本地 Ollama |

“实时研究”表示本次请求供应商，研究对象仍是指定年度历史数据，并非实时行情。公开接口可能限流或调整字段，使用结果需与披露核对。

连接设置优先于旧环境配置。首次无配置文件时，继续读取进程环境变量、产品 .env、用户目录 .vibe-trading/.env。不要将密钥发到聊天里。

新保存的密钥使用 Windows DPAPI 加密，保存在 var/connections.json；读取接口不返回密钥。留空保留旧密钥，换服务域名需要填新密钥或清除旧密钥。当前加密存储仅支持 Windows 当前用户，不能直接复制到其他账号使用。

启用模型时，问题、最近对话、当前研究事实、已选材料片段及工具结果发送到该轮选定的模型连接。历史记录保存于本机。它是本地个人产品，尚不具备多用户认证和公网部署设计。

## Agent 的执行方式

每轮以“模型决定下一步 → 调用受限工具 → 读取工具结果 → 决定继续或回复”循环运行。支持直接讨论与追问，不要求每次走同一条工作流。

当前工具：证券搜索、建立财务底稿、查找年报全文、接入资料、PDF 多词检索与按页查阅（含扫描页 OCR）、联网搜索、读取网页、阅读官方公告PDF、整理研究问题、记录问题证据、深度研究成稿、估值方法清单、估值方案提议、执行已采用方案、直接估值计算、报告修订。

- 每轮最多 8 次模型决策；15 分钟预算在动作边界检查。深度研究工具另有 10 分钟预算、最多一轮针对草稿的修订。时间预算在调用边界检查并限制模型请求超时；手动暂停可终止本地任务，不必等待外部请求返回。
- 每轮最多两次全文检索，其后读取命中页或总结缺口；最后一次决策提示模型收束答复。工具预算仍可能耗尽，已完成的结果会保留。
- 同一对话同时只运行一轮，全局最多两个 Agent。消息、动作、输入参数、结果和模型用量保存在 SQLite。
- 每轮冻结模型连接 ID；切换默认模型不会改变已开始的这一轮。配置本身仍可编辑。
- 最近 24 条消息、最近 4 个估值结果和已查阅来源进入模型上下文；资料跨轮保留，正文按总长度预算截取。更早聊天仍保存，尚无长对话自动摘要。
- 新估值数值须能对应用户提供的假设；“其余不变”可沿用同方法上一版输入。新数值未提供时应继续讨论。
- Agent 建议的参数先保存为待确认方案，记录用户采用的消息后才计算；多个方案需要明确选定，不能自动挑选。
- 明确要求修改报告或重算估值时，程序检查是否真的调用对应工具，避免只给计划或重复征求确认。
- 明确要求“不联网”“只用已有材料”“不修改报告”“不计算估值”时，执行层限制对应工具；这类中文约束采用规则识别，复杂或含糊表达仍需留意执行过程。
- 普通限制默认只作用于当前轮；“以后不联网”等明确的持续要求才保存为后续约束。后续明确授权可调整本轮限制，撤销持续限制需明确说明。界面展示实际生效的限制；“不使用任何工具”会在工具派发层阻止调用，而不只提示模型。
- “继续未完成部分”只接续最近一轮未完成且仍属于同一研究的任务，保留原目标、约束和已完成步骤。相同参数下可用的成功结果可复用；空搜索、没有正文的读取和失败结果不会阻止重试。报告输入没有实质变化时复用已保存报告；续查补充了证据、问题答案或其他相关输入后，可在原有报告保存授权下更新新版本，仍受当前禁止写报告等限制。续查仍需模型决策并受预算和外部服务可用性限制，不是后台进程的任意断点恢复，也不保证所有未完成项都能解决。
- 允许更新报告但明确要求“不修改研究问题”时，报告可分析既有问题，嵌套规划和保存步骤不会改写问题台账；问题写入权限与报告写入权限分别检查。
- 明确要求打开正文但尚未读取时，最多补读两次已有搜索结果；界面按实际工具记录显示新增正文、引用旧材料和未完成项。取得正文不代表已证明结论，也不保证覆盖全部研究问题。
- 报告按引用的估值版本或生成时快照提示是否沿用旧情景；缺少关联的旧稿会标记无法确认。更改估值不会自动改写报告。章节和核实清单的“继续查证”只预填聊天，发送后才执行。
- 深度报告区分业务、竞争、经营质量、估值分歧、催化剂、风险与验证计划。支持PDF页和网页引用，不再强制把业务判断塞入三项财务指标。旧简报仍用原财务校验；新报告验证引用存在与披露日期，并由模型进行反方审阅，不代表全部数字、因果或投资判断经过独立验证。
- DeepSeek 的深度报告撰写和审阅启用官方思考模式；计划和普通对话保持较快响应。其他服务保留各自协议默认行为。界面展示分析结论、证据和操作过程，不展示模型内部推理文本。
- 已有资料足够时可要求“根据已读原文修订，不需要重复联网”。修订工具复用来源、重新分析并保存新版本；这一快捷路径只做引用校验，不额外调用反方模型，报告中会如实注明。生成失败后的修订也复用已取得材料，避免整套搜索重复运行。
- 同方法最近一版的参数、财务基数及结果相同时，重复提交返回已有结果；中间插入其他方法也不会重复保存，既有历史仍保留。
- 模型解释仍需审阅，程序不能全面验证金融推理或自然语言中的全部事实。

基础取数工具保留：读取材料 → 证券确认与两年财务 → 交叉核对 → 代码计算。新建实时研究并勾选模型时，进一步执行联网深度研究；对话 Agent 建立底稿后自行选择下一步。样例回放保持离线、确定性、不调用模型。

借鉴记录与华宇软件对话审计见 [reference-review-v0.3.md](docs/reference-review-v0.3.md)。界面参考 [shadcn Dashboard](https://ui.shadcn.com/examples/dashboard) 与 [Linear](https://linear.app/changelog/2024-03-20-new-linear-ui) 的中性色、层次与按需展开设计。DeepSeek 参数依据 [官方思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/)。

三种模拟买方视角的使用评审、另外三位代理的复核与执行记录见 [买方评审](docs/buy-side-review/README.md)。本轮优先修复实际复现的问题，保留现有视觉主题；章节级版本差异比较暂未实现。

## 估值方法与边界

| 方法 | 输入与计算 | 缺失处理 |
|---|---|---|
| PE | 无冲突的归母净利润 × 下一期增长假设 × PE | 缺少正利润时停止；股本仅用于每股换算 |
| PS | 无冲突营业收入 × 下一期增长假设 × PS | 此处为市值/收入，不是 EV/Sales |
| PB | 用户提供归母净资产 × PB | 归母净资产尚未自动取数核验 |
| DCF | 正的基期 FCFF、恒定预测增速、1–10 年、WACC、永续增长率 | 不拿 CFO 代替 FCFF；WACC 必须高于永续增长 |
| EV/EBITDA | 用户提供预测 EBITDA × 倍数 | 未取到 EBITDA 时不从净利润猜测 |
| DDM | 基期每股股利 × (1+永续增长率) / (股权成本−永续增长率) | 单阶段 Gordon 模型，股权成本必须高于增长率 |

DCF 和 EV/EBITDA 先得到企业价值。**股权桥接扣减项 = 净债务 + 少数股东权益 + 优先股 − 其他非经营性资产**。未填桥接项时不给股权价值；未填摊薄股本时不给每股值，不自动填零。所有结果是探索情景，保留输入、公式、来源、限制和历史版本，不代表目标价建议。

当前 DCF 尚未自动建立完整三表、分部收入预测、逐年再投资或融资计划；PB、EBITDA、FCFF、股利等需要补充资料或用户假设。多方法选择已经实现，完整自动化建模仍是后续研发重点。

## 仍需继续研发

结构化事实仍聚焦营业收入、归母净利润、经营现金流两年年度数据。PDF 已支持文字检索与扫描页查阅；复杂跨页表格、OCR 金额、多币种尚无完整自动核验。供应商历史修订完整性未独立验证，不能作为严格时点回测数据。
