# v0.5.1 验收记录

验收日期：2026-10-17。本次根据用户要求，为备忘录增加明确的投资研究建议，并使用伊利股份（600887.SH）与中芯国际（688981.SH）进行真实模型全流程测试。两家公司仅用于产品验收，本记录不构成对其股票的投资推荐，也不将条件建议或测试参数作为已验证估值。

## 本次行为

- 新的完整备忘录明确保存买入、持有、减持、回避或观察建议，区分当前可执行的研究判断、条件满足后才行动、证据不足暂不决策。
- 建议分别说明未持仓与已有持仓情境，包含适用期限、置信度、建仓与退出条件、关键风险和重新评估触发条件；不假定用户真实仓位。
- 程序获取截至研究时点的未复权收盘价，冻结日期、证券、币种、实际来源及估值情景。本次两份报价均来自 Tushare，交易日为 2026-10-16，不是盘中实时价格，也未与独立行情源交叉核验。每股情景空间采用确定性计算，计算正确不代表假设已获得研究支持，不能把企业或股权总价值包络直接当成每股目标价。
- 建议置于备忘录顶部，保留研究立场。旧版本无建议字段时显示未形成明确建议；旧建议仅改标题时不会自动变成最新判断。报价或截止日变化会提示重新核验。
- Markdown、HTML 与完整证据包包含明确建议及冻结依据；原始行情单独留档，存在实际历史报价时才导出行情历史，包内清单记录逐文件 SHA-256。

## 真实测试路径

两份测试研究及聊天保存在正常本地产品中，重启后仍可查看。测试使用现有模型连接与 Tushare 连接；不在文档中记录密钥。

1. 建立公司财务底稿，取得并实际查阅公开年报 PDF，查询截止日前市场收盘价。
2. 与 Agent 讨论估值方法，由用户明确采用探索假设后保存估值，按用户指定轴值生成敏感性矩阵。
3. 登记 2024、2025 年度收入、归母净利润与经营现金流期间记录，缺少季度资料时保持缺失。
4. 联网查找并阅读行业、经营与风险原文，生成带明确建议和持续跟踪指标的深度备忘录，对完整草稿执行单独的反方模型审阅调用，并在后续修订中保留其意见。
5. 浏览器核对对话、资料、估值、期间记录、建议卡和来源入口；下载四类导出，检查证据包文件哈希。
6. 每家公司记录一条重新核对既有基线的独立跟踪观察，标为“仍无法判断”，明确没有取得新期间数据；检查观察绑定当前报告版本，记录前后备忘录内容哈希不变。
7. 逐条比对开发前 5 份研究、5 段对话、6 份文档的原始 SQLite payload 哈希，并检查数据库完整性。

## 本轮发现并修复的问题

- 阶段授权识别曾把“先取资料、暂不深研”和后来“开始深研并保存”混在一起，导致已授权的下一阶段受阻；现在按用户本轮明确授权与有效持续约束解释任务，既不提前深研，也不要求重复确认已授权的保存。
- Agent 曾尝试在同一轮提出新估值方案后自行采用。采用动作必须对应用户已看到并明确选择的方案，不能由模型自己的下一步决定充当确认；同轮自行采用会被拦截。
- 把已有年度事实登记为期间记录时，模型重复抄写金额、单位和摘录，容易产生不必要的匹配失败。增加按已有 `fact_ids` 导入原值、来源及口径的路径；新原文记录仍执行原来的来源和金额校验。
- “保留已有估值、不重算”一度被扩大解释为禁止所有计算，连期间分析和敏感性也被挡住。增加 `no_valuation_recalculation` 窄约束，只阻止重算或重新采用主估值情景，不阻止用户另外授权的财务分析和敏感性。
- 未完成报告的续接曾因跨轮任务范围识别不准，把已授权的完整报告恢复误当成只改局部，或使局部修订受旧约束阻挡。续接绑定真实任务链和当前授权范围，完整恢复与局部编辑分别处理。
- 部分条件性建议可能把评级与持仓动作写成相互冲突的结论；对明显矛盾增加校验，保留模型修复与失败记录。
- “不追加仓位”“暂不建仓”等否定动作一度被识别成肯定的加仓或建仓，与观察建议产生假冲突。动作校验现保留否定范围，同时继续拒绝真正相互矛盾的评级与动作。
- 最后只读审查发现，整句中出现“若”可能掩盖另一分句已经要求当前买入的矛盾。条件判断收窄到动作本身所处的局部范围，避免用一句话中的条件词放行无条件的当前交易动作；两份实际建议重新归一化通过。
- 敏感性参数引用仅因“增长轴0、5、10”和“增长轴为0、5、10”相差一个连接词就被拒绝。现在只对轴值前受控的连接表达作兼容，数值仍逐一核对用户原话，否定参数与未确认数值仍会阻断。
- 财务摘要把主营业务收入与营业收入混用，暴露出生成上下文未充分携带指标标签与口径。补充明确的财务字段及口径信息，并将期间回答核验接入最终答复流程：对可识别的期间、指标及金额与本轮底稿比较，发现矛盾先返回修正反馈；再次不一致时不采用原总结，直接列示已保存期间结果。该守卫保留主营、分部、母公司、预测等口径边界，不声称覆盖任意自然语言或消除所有语义混用。
- 旧建议的行情或估值引用需要与生成时依据冻结，局部文字修订不得悄然更新旧判断；增加冻结依据、来源指纹及变化提示。
- 最后核对发现，伊利已保存建议后又读取年报第 7 页，来源内容变化使建议依据标为过期。这与新增跟踪观察造成报告整体“待同步”不同；增加终验条件，要求建议本身的来源新鲜度为当前。真实研究轮重新核对建议并保存第 6 版，仅修改可编辑字段中的投资建议；来源同步已有最新读页记录，第 7 页更新正文及读取时间，第 20、22、29 页更新读取时间。没有清除提示来绕过核验，也没有把原因全部归到跟踪观察。
- 伊利建议局部修改后，原研究立场、估值论点及估值章节仍保留旧的判断口径。第 4 版修订立场与估值论点，第 5 版修订估值章节，保留旧版本及逐字段变更供对照；不以建议卡更新代替正文对应位置的核对。
- 中芯国际同时存在 A/H 股，不能把 A 股价格乘全部股数称作实际合计市值。最终建议及对应正文已明确这一乘积只是假设全股本按 A 股价格定价的参考。已读年报第 111 页取得 A 股 1,999,562,549 股、H 股 6,000,845,486 股、合计 8,000,408,035 股；即使已有股数划分，缺 H 股价格与汇率时仍不能声称已取得真实合计市值，也不据此直接宣告低估或高估。原反方意见仍保留为待复核，内容修订不自动等于意见已经解决。
- 条件观察原先显示为“条件满足后观察”；改为“观察，暂不行动”。只有来源齐备且与冻结估值、日期和币种匹配的价差可显示。
- 浏览器显示“已接入材料 · 0”，但实际年报已接入。原因是资料刷新依赖高频变化的对话更新时间，每次先清空并作废上一请求；改为按会话和材料集合刷新，同会话保留已加载列表，旧请求不能覆盖新会话，加载与失败不再冒充零材料。
- 新增敏感性等工具在过程视图显示内部英文名；补齐全部注册工具的中文标签，并为未来未知工具提供普通中文回退。
- 情景每股价值曾在建议卡展示完整 Decimal 长小数；页面改为两位小数，假设空间最多两位，保存值与导出仍保留原始精度。
- 财务期间页复用原事实后曾显示内部状态码 `fact_ledger`；改为“已存事实复用 · 保留原核验状态”，原始记录另显示“接口单源”等原核验标签，避免把复用解释成重新或双源核验。
- 建议正文偶尔出现 `exit_conditions` 等内部字段名。建议卡与可读 Markdown/HTML 仅在展示时将已知字段词转换为“减仓或退出条件”“建仓或加仓条件”“重新评估条件”；保存的原文、JSON、来源链接及指纹不变，不重新调用模型改写。
- 正式导出验收发现，中芯新一轮明确复用未发布草稿后，原草稿的 6 条反方审阅意见仍在原始尝试和审计包内，却未继承到当前报告审阅区。首次终验因此未通过。修复明确复用时的意见继承后，真实修订生成第 5 版，6 条原意见均以“待复核”恢复，并保留原始尝试、对话轮次与步骤标识。对比可编辑正文字段只有标题改变，来源完全不变；未覆盖回旧稿正文，也未重新调用模型复审。重新启动后，最新 API 与四类导出再次通过留存检查。

## 已有校验成功拦截的错误

中芯国际的一次未发布全稿把净债务写成 **4.64 亿元**，而已读 PDF 第 28 页为 **4,642,668 千元**，换算约 **46.43 亿元**，相差十倍。金额与单位校验拒绝保存并返回具体反馈，模型据此修订；错误稿未发布。本例说明既有防线成功捕获该错误，不是放宽金额校验后通过，也不代表所有财务语义错误都能自动识别。

尚未完成的尝试、结构校验拒绝、预算中断和修复重试均保留在两段聊天与审计记录内，不计作完成。最终两份报告状态均为 `completed_with_gaps`，流程结束与研究信息完整是两件事。

验收脚本为 `tmp/v051/verify_release.py`。预检可用 `--skip-exports`，此模式必定保留“导出尚待验收”并不会宣称整体通过。终验只调用读取 API、GET 导出和只读 SQLite；正常证据包下载会留下应用原有导出审计事件，不修改研究、聊天或文档 payload。该脚本及详细测试资料位于本地临时目录，不随公开源代码提交。

反方审阅需区分两个阶段：完整深研草稿曾执行单独的反方角色模型调用，以及其后的局部修订。这里的“独立”指独立调用，不代表不同模型服务商交叉审查、外部研究员复核或人工投资批准。两家公司已发布版本均未标记当前独立复审通过；实际审阅证据位于原未发布草稿，当前版本各保留 6 条意见，全部待复核。不能因当前 `independent_review_performed=false` 就否认早先审阅，也不能把早先审阅说成当前建议已经再次通过独立复审。脚本分别记录审阅尝试、已发布审阅版本、当前意见保留情况与本版的明确边界。

“观察”在这里包含可执行的暂不建仓、暂不加仓和重新评估条件，不是强行给出买入或卖出。28.20 元与 102.66 元是本次冻结的收盘价；34.56 元与 29.3608 元是探索情景算术结果，不能作为已验证目标价或据此断言高估、低估。两家公司暂未取得可靠价值判断所需的全部证据，因此没有为了通过测试而制造无条件交易建议。

本次覆盖年度三项核心财务的两年记录、每公司一张 3×3 敏感性矩阵、年报页读取、网页正文读取、深研生成、修订、历史反方意见保留、基线复核观察和导出。伊利保留 19 条报告来源，中芯保留 21 条；这些数量不等于独立来源数量或完整覆盖。测试不证明所有年报页面、季度报表、行业和客户资料已穷尽，也不证明所有自然语言错误都能自动检出。

跟踪观察仅重新核对已存在的基线，没有取得新的期间数据，不能据此声称指标已改善或恶化，亦未验证长期自动监控。中芯客户披露范围、行业资料以及两家公司原反方问题仍需继续核实，保留原意见是审计与后续研究入口，不表示已自动解决。

建议自身的行情、估值和来源新鲜度必须为当前；报告整体还可能因保存后新增独立验收跟踪观察而保留“报告待同步”提示。二者分开核对，不能把建议过期解释成跟踪观察，也不宣称正文已吸收所有最新独立记录。
