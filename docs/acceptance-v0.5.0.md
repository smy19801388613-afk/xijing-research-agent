# v0.5.0 验收记录

验收日期：2026-10-17。目标是补齐第 2、4、6 题的显著能力缺口。规则依据为项目根目录的《2026年北京市大学生金融人工智能竞赛通知》PDF，官方通知见 [北京市教委页面](https://jw.beijing.gov.cn/gjc/tzgg_15688/202608/t20260827_4839055.html)。本记录不代表主办方认定合规或评分结论。

## 功能与使用入口

| 对应方向 | 本次实现 | 验收重点 | 当前边界 |
|---|---|---|---|
| 第 2 题：财报分析 | 独立“财务期间”入口；年度/半年/前三季/单季；同比环比；扣非桥；利润与现金流方向背离 | 累计流量可拆分，余额不能拆分；缺基期、冲突、重述不一致、未来公告阻断；非正基期显示金额差 | 模型从已读材料登记或用户录入；尚无任意版式全财报自动抽取及完整三表勾稽 |
| 第 4 题：估值分析 | 六方法双轴敏感性、情景包络；PE/PS/PB 可比依据 | Decimal 计算；WACC≤g 等无效格排除；来源与基数指纹；不同日期/币种/财务期间不混合 | 倍数与假设仍需讨论确认；可比业务与数值待研究员核验；无自动行情批量可比筛选 |
| 第 6 题：研究备忘录 | 新深研报告的持续跟踪指标、原文基线、支持/推翻条件、后续动作；独立观察记录 | 日期/正文/连续摘录校验；数值阈值标为未确认假设；观察绑定报告 revision 与 hash | 跟踪由用户或 Agent 发起，未实现定时监控；旧报告没有字段时不会自动新增；观察支持关系待复核 |

既有的证据、论点、反证与失效条件继续保留。官方第 6 题没有要求必须给出买卖评级，本次没有强制增加评级。

## 隔离与保留

测试目录为 `tmp/v050-*`，不使用生产研究库写入测试。生产初始快照与逐条 payload 哈希保存在 `tmp/v050-competition/before.sqlite3`、`baseline.json`。旧研究、聊天、PDF记录不迁移，不回填跟踪字段。新分析的原始数据、来源与版本单独保存，报告修订仍需显式授权并校验当前报告版本。

普通导出增加期间、敏感性、可比及跟踪信息，明确当前工作底稿与已保存报告的区别；证据包增加 `analysis/`，所有文件纳入清单哈希。删除期间条目保留删除档案，不擦除历史。

## 测试方法

1. 对财务期间、估值、跟踪各自做隔离测试，再测试 Agent 权限、完成条件、引用、报告同步、路由与导出联动。
2. `scripts/evaluate_periods_v050.py`：12 个固定合成用例，独立检查 Q4 拆分、跨年环比、半年同比、非正基期、余额、口径隔离、扣非桥与现金流信号。
3. `scripts/evaluate_valuation_v050.py`：8 个固定合成用例，独立手算 PE 包络、恒定 FCFF 的解析 DCF、股权桥接、无效格、同行中位数与亏损剔除。
4. 浏览器检查真实表单、结果、分页和历史；用本机已配置模型在隔离美的样例中执行期间分析、敏感性和报告修订。该样例不是新增独立金融事实核验。
5. 从无旧依赖、无生产数据和无模型凭据的目录重建环境，安装锁定依赖、构建页面、回放指定样例及运行固定评测和联动测试。

固定用例全部通过只说明这些算术和规则被覆盖，不是财报提取准确率、投研结论准确率或投资收益评测。

## 验收中发现并修复

- 财务来源目录与扩展分析互相调用导致递归；改为先获得排除扩展的原始来源目录，动态重验来源后生成派生引用。
- 新增输入未核验时可能被派生引用提升为已确认事实；扩展引用仅可支持明确的条件推论，来源变更时阻断。
- 新工具不识别“不要保存期间记录”、敏感性只截取被否定参数、读取结果冒充保存；补齐写入权限、完整分句检查与独立完成条件。
- 动态工具复用旧结果可能拿到旧期间分析或旧报告标识；禁止复用这六个工具的旧执行缓存。
- 局部改论点标题与原跟踪关联冲突；只对完全未改的跟踪对象保留原关联，并显示待复核提示。
- 期间表先展示大量不可计算项，遮住有效结果；改为有效结果置前、每页 8 行、独立入口。
- 报告失败后只改工具描述会被当作新尝试；按实际人类任务识别重复失败，避免无进展调用持续消耗预算。
- 真实模型将基线写成“53,345,930 千元（2025年）”，年份被误判为金额；现在只对与基线期间一致的明确日期注记豁免金额匹配，错误年份与实际金额仍校验。
- 真实报告将每股股价与总股权价值包络直接比较；新增基于已保存敏感性输出的单位校验，要求先用股价乘股数换算总市值，或把股权总价值除股数换算每股价值。企业价值须先桥接股权价值，缺数据明确待补。
- 原始来源变化而侧边分析记录未变时，报告同步提示可能漏报；报告依赖现包含当前来源指纹。
- 普通导出曾直接展示期间分析 JSON；改为可读比较表，完整原始数据保留在审计导出与证据包。
- HTML/打印导出原先把新增 Markdown 表格作为普通段落展示；新增只支持生成内容所需格式的安全渲染，标题、表格和多行原文可读，所有输入转义，不执行原始 HTML 或链接代码。
- 真实局部修订时，工具已返回跟踪指标，但旧上下文投影未识别新字段，模型反复读取后耗尽预算；补齐新增工具的结构化结果投影。动态读取仍执行当前数据，若结果连续完全相同，则提示复用并触发无进展保护；未增加决策次数上限。
- 新增分析成果的提前结束检查遗漏了映射项；改为默认保留未完成事项，不能因读取过指标就宣称已保存报告或观察。

浏览器可比算例使用清楚标注的合成公司：10 倍、20 倍纳入统计，-5 倍排除，中位数 15 倍，未自动应用到原估值情景。新增观察保存时，报告内容和版本不变；后续局部修订后，该观察仍保留并绑定旧报告版本，页面显示旧版观察数量。

真实模型使用本机现有 `deepseek-v4-pro` 连接。早期尝试分别遇到原文不足、5 分钟预算到期、日期注记误判、上下文投影遗漏；未保存新报告时均保留旧版并显示未完成。修复后，正常后台执行以“继续未完成部分”恢复任务：先生成带跟踪指标的第 2 版，再只修正跟踪里的单位比较，保存第 3 版。最后一轮共有 4 次模型请求（含结构修复），累计 98,641 tokens；没有联网或读取新页，不能据此宣称已做新的行业研究或补齐真实金融证据。

验收脚本曾直接调用执行函数，被在线服务判为未登记的孤立进程；改用正式后台启动路径后通过。干净环境初次复用受控空网络白名单，使两个普通模式 mock 测试在网络策略层提前失败；最终全套在普通模式、全新空用户目录和环境白名单下通过，未复制旧配置或密钥。上述失败日志保留，不计为成功样本。

详细日志、隔离聊天与报告保存在 `tmp/v050-competition/` 和 `tmp/v050-browser-data/`；这些目录不随公开源码上传。产品当前能力及边界以上表为准，提交材料、演示视频、贡献说明和官方评分仍需单独完成。
