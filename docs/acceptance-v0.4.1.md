# v0.4.1 实现与验收记录

日期：2026-10-13。版本：v0.4.1。

本版整合 PR #2 的比赛工作区、派生事实状态和问题级证据清单，以及 PR #3 的对话约束与正文查证改进；进一步补充问题编辑、报告同步、材料预检和未完成任务续查。本记录列出本轮实现范围、验收判定条件与真实验收边界，执行结果来自本版检查。

## 实现范围

### 1. 问题与证据可以持续维护

研究规划提示首次聚焦 3–5 项关键问题，已有问题可覆盖时优先复用；程序每次最多接纳五项模型规划结果，人工批量添加接口保持兼容。程序去重处理空白、标点与大小写，不把语义相似度当成自动合并依据。

每项问题支持高、中、低优先级、完成条件编辑、归档与恢复。编辑保留稳定 ID、答案、证据与历史；修改问题含义或完成条件会降级并提示重新核对。归档项保留记录，但不进入活跃问题完成度。仅修改优先级不会使报告过期。

答案编辑保留多条支持/反方证据、反方说明、缺口及下一步行动。用户明确删除某条绑定后才移除该绑定。页面内草稿可收起继续编辑；草稿不等于已保存研究，刷新或切换研究后不保证保留。运行中的研究或关联对话尚未完成时，人工问题编辑接口会拒绝并提示等待。

### 2. 证据资格与研究判断分别处理

问题答案、报告引用与聊天资料覆盖使用 `app/evidence_policy.py` 的共同资格规则：

| 资料状态 | 可做什么 | 不能据此声称什么 |
|---|---|---|
| 只有搜索摘要或文件链接 | 保留为检索线索或说明缺口 | 已读取正文、问题已被充分回答 |
| 已取得且日期符合截止日的正文 | 绑定原文，参与带来源的研究分析 | 已独立证明因果、盈利预测或投资判断 |
| OCR 文字 | 查阅并用于明确标注的推断，继续核对原图 | 数值或观点已经核验 |
| 日期未知或无效的正文 | 保留材料与日期缺口，参与有边界的推断 | 该资料在历史截止日内已经公开 |
| 关联财务事实冲突 | 显示冲突与待核对项 | 已解决冲突的支持性结论 |
| 晚于研究截止日 | 排除出本次历史研究的有效引用 | 用后来信息证明当时已知 |
| 代码计算与用户估值情景 | 说明公式、输入与探索结果 | 新增了一份独立原文证据 |

问题有支持状态，还需实际答案、匹配的摘录、适用的来源日期、反方说明及缺口处理。摘录匹配只确认来源中存在该文字，支持关系仍是模型或人工判断。规则不是通用金融语义验证，也不证明来源相互独立。

历史研究按固定截止日判断资格，旧材料不会仅因年份早就自动失效。来源变化检测比较本地已保存的内容、日期和资格，不会为显示状态额外联网，也不会自动监测外部网站更新。

### 3. 研究进展与报告版本有关联

新保存的报告冻结所用问题与证据指纹。答案、问题含义、引用内容或日期变化后，显示报告待同步；引用来源即使未绑定问题，也参与报告变化检查。重读相同内容而仅更新获取时间，不应被当成实质变化。

“通过对话更新报告”发送明确更新请求，依据已有问题、答案、支持和反方证据修订，不重新联网、不改变估值参数。成功保存新版本后保留旧稿；这是报告级同步提示，尚不提供自动定位每一处受影响句子的章节差异功能。

模型生成期间若问题或所引来源又被修改，保存前会拒绝覆盖，保留现有报告与最新答案，要求依据最新证据重生成。没有记录问题快照的历史报告显示“尚未建立对应记录”，不追写旧历史。

普通报告导出保留当前活跃问题，审计版包含归档问题；二者均保留适用的来源状态与同步提示。当前问题清单可能比报告正文更新，提示不会将旧报告正文自动改成新答案。

### 4. 对话约束可见，未完成任务可继续

聊天显示当前有效约束和明确设置的持续约束。普通“不联网”等要求作用于当前轮；“以后不联网”等明确持续要求才进入后续约束。模型可用工具列表与执行检查共用工具能力声明，包含工具内部会发生的联网、报告保存或计算行为。“不使用任何工具”在派发前阻止调用。

失败、取消或预算耗尽后，界面分别显示已完成步骤、未完成项和报告是否已经保存。“继续未完成部分”只接续最近一轮有剩余事项且仍属于同一研究的任务，沿用原始目标、限制和成功结果。相同工具参数下可用的成功步骤可复用；空搜索、没有正文的读取、失败和不可用结果不会被当作可以复用的完成项。

报告复用比较可用来源、问题状态、估值与计算输入。同输入时复用已保存结果；续查取得新原文或问题答案等相关输入变化后，可按原任务的报告保存授权更新新版本，再次遇到相同输入时复用。禁止修改报告的当前约束在复用和执行前都有效，续查本身不扩大授权范围。允许保存报告但禁止修改问题记录时，嵌套研究规划与报告保存均保留问题台账，模型擅自生成的问题更新不会落库。

这不是任意进程检查点恢复，也不保证所有剩余事项都能完成。继续执行需要可用模型，仍有单轮预算与外部服务限制。中文约束采用规则识别，复杂、含糊或矛盾表达仍需通过界面确认实际生效限制。工具成功、取得正文、报告保存与金融问题得到正确答案是不同状态。

### 5. 比赛材料预检与提交可追溯

在独立比赛工作区选择材料后，预检检查公司、年度、研究截止日、文件完整性，以及结构化材料的数值、单位、币种与年度合并口径。结构化预检与实际执行共用行资格规则，展示采用/排除行数和原因；创建任务时再次检查并保存材料选择记录。

模型预检仅检查是否配置模型及凭据、接口来源是否许可，**不发起连通性或模型调用测试**。`ready` 不代表密钥有效、额度充足、模型可用或回答质量达标。PDF 预检的可读和日期检查也不保证复杂版式能抽取出核心财务数据。可取消模型选项仅核对材料；这不能替代比赛所要求的真实大模型使用证明。

提交包分别保存原始 JSON/CSV 和 `.meta.json`，防止 JSON 原文被同名元数据覆盖。文件哈希用于校验字节完整性，不判断财务内容真伪。审计仍覆盖所选工作区，应用层网络许可与目录限制仍不替代操作系统隔离。

## 验收项目与判定条件

以下项目是本轮需要验证的行为，不构成真实模型成功率或金融准确率结论。

| 项目 | 判定条件 | 对应回归入口 |
|---|---|---|
| 问题编辑与归档 | 保持 ID、答案、多条证据和历史；语义修改待复核；归档不计活跃完成度 | `tests/test_questions.py` |
| 多证据编辑 | 仅改答案不清空证据；支持与反证均可增删；下一步行动保留 | 页面“问题与证据”与问题 API |
| 统一引用资格 | 摘要、空正文、OCR、未知/未来日期、冲突与计算来源得到不同资格；旧材料不因年龄自动失效 | `tests/test_evidence_policy.py`、`tests/test_deep_research_v03.py` |
| 报告同步 | 变化有提示；明确更新后建立新快照；旧稿与估值保留；生成期间并发变化不被标成同步 | `tests/test_questions.py`、`tests/test_report_state.py` |
| 约束与资料覆盖 | 禁止工具/联网/报告写入确实阻止对应调用；允许报告但禁写问题时台账不变；搜索摘要不算正文；新读与复用资料区分 | `tests/test_agent_constraints.py`、`tests/test_deep_research_v03.py` |
| 续查 | 保留原任务、约束和可用成功结果；拒绝过期或跨研究续查；报告同输入复用、输入变化后在原授权内更新 | `tests/test_agent_resume.py` 与页面“继续未完成部分” |
| 比赛预检 | 错公司、日期和口径有明确说明；无网络调用；创建时复核；模型配置就绪不冒充实测 | `tests/test_competition_preflight.py` |
| 提交包 | JSON/CSV 字节与输入一致，原文与元数据路径不同，清单哈希正确 | `tests/test_competition_preflight.py`、`tests/test_competition.py` |
| 交付与版本 | 页面、健康接口和启动版本一致；Markdown/HTML/ZIP 可查阅同步状态与来源 | 前端构建、启动与导出回归 |

## 执行记录与尚需补充的真实验收

自动回归使用临时数据库、本地合成材料和模拟服务；其用途是检查边界、数据保留、失败路径和确定性行为。最终 `python -m pytest -q`：342 项通过、1 项跳过（Windows 未授予创建符号链接权限），耗时 36.69 秒；保留一条既有 Starlette/httpx 弃用提示。前端 `npm run build`（TypeScript + Vite）、`pip check` 与 `git diff --check` 均通过。

本轮已完成以下本地浏览器与受控工作区验收：

- 在问题编辑表单仅修改下一步行动后，三条证据绑定（两条支持、一条反证）完整保留；优先级、完成条件编辑、修改含义后的降级、归档与恢复正常。
- 问题变化后显示报告待同步；点击更新报告按钮只发送一次明确的更新请求，不代表该请求已通过真实模型生成报告。
- 续查请求携带正确的 `resume_from_turn_id`；模型成功、失败与恢复行为使用模拟响应检查。
- 受控工作区使用合成材料完成预检和实际执行：五行采用、一行排除，排除原因可查阅。
- 390 像素窄屏没有横向溢出；本地生产构建页面显示 v0.4.1，检查过程中没有控制台 error。
- 原始 JSON/CSV 与导出材料逐字节一致、元数据路径分离，由自动回归覆盖。

本轮不以模拟响应冒充真实大模型验收。后续应使用可授权的真实材料、固定截止日和真实可用模型，完成一次从研究问题、来源查阅、反证、报告更新到提交包的全过程，并由研究员独立复核数字、会计口径、证据支持程度和结论。

本版未实现完整自动三表、自动 FCFF 桥接建模、行情与同行估值平台、逐句报告影响分析、策略回测或实盘交易。工具权限登记中的预留名称不表示对应金融功能已完成。
