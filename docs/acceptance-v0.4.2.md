# v0.4.2 长报告生成与暂停修复

日期：2026-10-14。

## 诊断依据

读取现有紫金矿业研究对话、报告尝试记录和本地 worker 日志，确认 5 次长度截断发生在深度报告生成或修订阶段。普通聊天模型调用正常，问题并非 Tushare Token。

此前深度报告正文预算 7,800 tokens，加 8,000 的思考预留，实际合计上限仅 15,800。DeepSeek 的 `max_tokens` 同时约束思考和正文，见[官方接口说明](https://api-docs.deepseek.com/api/create-chat-completion/)。已有成功记录中，一次正文约 8,416 tokens，加思考约 4,934 tokens，说明原预留缺少余量。旧版没有记录失败调用用量，因此不能推断那 5 次失败各自的精确思考占比。

报告输入又同时带入两份重复原文目录。本次对同一研究只读测量，目录序列化长度由 229,479 字符降为 123,214 字符；65,000 字符的原文预算由两个目录共用，原始资料和问题台账不删改。

暂停旧实现只设置取消标记，需要等待阻塞的外部 HTTP 调用返回。界面也未消费取消接口的最终状态，进一步依赖后续事件刷新。

同时发现自动年报索引在研究写事务内再次写入文档元数据，造成 SQLite 锁冲突；另有问题状态取值错误、引用摘录不匹配导致修订失败，均纳入本次修复。

## 实现

- DeepSeek 思考调用首次合计额度至少 32,768 tokens；当前 7,800 正文预算的长度恢复额度为 49,152。每个逻辑调用最多重试一次，受工具时间预算约束，不对网络或权限错误无限重试。其他接口保留原始首次额度。
- 截断 JSON 不拼接、不作为有效草稿保存；重试基于原始证据生成完整结果。记录实际额度、结束原因、每次与合计用量；不保存私有思考文本、密钥或原始截断响应。比赛审计保留数值用量，同时继续脱敏凭据。
- 报告与问题证据目录按来源 ID 去重；问题上下文去掉编辑历史。提示模型优先更新最多 5 个有进展的问题，使用短的连续原文摘录。章节状态与问题状态分别列出，校验失败反馈包含具体问题和来源 ID。
- 失败诊断即时写入尝试记录。完整但未通过结构或引用校验的草稿只进入尝试记录，正式报告仍需完整校验及输入版本核对后才能替换。
- 年报索引写入移到研究事务之前，消除嵌套 SQLite 写入。
- 取消接口原子停止该轮、保留已完成结果，然后终止登记的本地 worker。进程身份由 PID 加创建时间校验；Windows 在同一个进程句柄上核验和终止，避免 PID 复用误杀。
- 旧 worker 的数据库写入和后续模型调用受执行作用域保护；迟到的取消请求、状态事件和终止回执不能覆盖新一轮。聊天创建的新研究归属该轮取消，不误停其他对话讨论的研究。
- 界面立即显示“正在停止…”，收到确认后恢复发送。终止异常时保留 worker 身份，显示后台连接待确认并提供重试。自由研究途中创建底稿后暂停，仍可继续未完成任务。

## 验收

- 全量后端：`python -m pytest -q`，**394 passed, 1 skipped**。跳过项为 Windows 符号链接权限；现有 Starlette 测试客户端弃用提示未影响结果。
- 新增回归涵盖：截断后成功恢复、二次截断、上下文限制、取消与截止时间阻止重试、供应商错误分类、失败用量、旧报告保护、证据输入预算、年报真实数据库索引写入、旧轮写回拒绝、进程身份校验和终止失败重试。
- 真实 worker 连接本地慢模型，模型尚未返回时取消在 1.5 秒测试阈值内完成，进程确实退出。
- 独立浏览器工作区实际发送和点击停止：模拟模型等待 25 秒时，取消接口约 29 毫秒返回，约 48 毫秒恢复发送，随后新轮回答约 1.9 秒显示。旧模型返回后，数据库及界面均未出现旧回答。上述数字为本机一次验收测量，不是线上延迟承诺。
- 浏览器路由模拟终止未确认与首次重试 HTTP 502：界面保持取消态、仍可发送；重试按钮在请求中禁用，两次重试均携带原 turn ID，成功后清除提示与错误。真实进程终止失败重试另由后端测试覆盖。
- 前端 TypeScript 检查与 Vite 构建通过。测试使用独立本地模拟模型，未替用户重跑完整的收费紫金矿业报告；真实长报告效果需后续实际生成验证。

## 保留与边界

升级前使用 SQLite backup API 保存数据库及记录哈希到被 Git 忽略的本地 `tmp/pre-v042-backups/`。现有研究、对话、文档、估值和报告版本继续使用原工作区。

本机 8920 服务已切换到 v0.4.2，健康接口工作区与前端构建一致；升级后核对现有 1 项研究、1 个对话、2 份文档的完整记录哈希，均与升级前一致。

暂停终止本地执行和连接，第三方模型服务端是否继续计算或计费取决于供应商。更大的额度与一次受限重试减少截断风险，但不保证任何模型和任意研究范围都能一次完成。引用匹配与来源资格校验也不证明金融判断正确。
