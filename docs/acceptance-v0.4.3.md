# v0.4.3 可调整执行预算

日期：2026-10-14。

## 使用方式与语义

聊天输入区上方的“执行预算”面板提供三个滑动条。展开后可调整本轮参数、恢复已保存默认，或显式保存为默认。连接设置提供同一组件，并支持恢复产品推荐值。保存失败会显示错误，不覆盖已有默认；仅拖动滑条不保存全局配置。

| 参数 | 推荐默认 | 范围 |
|---|---:|---:|
| 单次生成额度 | 49,152 tokens | 4,096–65,536，滑条步长 1,024 |
| 每轮时间 | 15 分钟 | 1–60，步长 1 |
| 主模型决策次数 | 8 次 | 2–32，步长 1 |

生成额度约束每次模型请求（包含截断重试），不是整轮累计 token 或金额。短决策按需分配较低额度，报告调用可在一次截断恢复中使用选定上限。供应商仍可能有自己的更低限制，接口拒绝时会如实返回错误。

主模型决策包括选择工具或组织回复；报告工具内部调用与供应商层的一次长度恢复不另计主决策。每轮时间约束整个 Agent，包括报告工具和阻塞中的 HTTP 请求。

## 执行与恢复

- 保存默认和本轮覆盖采用同一后端校验：完整三字段、严格整数、范围检查，拒绝布尔值、浮点值和未知字段。
- 发送时冻结预算、UTC 开始时间及截止时间到本轮上下文；修改默认不改变正在执行的轮次。运行期间滑条禁用并显示冻结值。
- 模型调用继承本轮生成上限与最早有效截止时间；对话内的深度报告不再被原先固定的 10 分钟预算提前中断。未进入 Agent 对话的独立报告仍保留原有保护。
- 主循环使用实际配置的次数，最后一次决策提示收束答复。达到上限保留结果，可调整预算继续。
- worker 中独立计时器在截止后原子终止该轮并退出自身，即使 HTTP 持续发送数据也能中断。超时单独标记 `time_limit`，不会误称为用户点击暂停。
- 已完成工具、报告和证据保留；迟到任务不能写回，旧计时器不会修改新轮。续查作为新轮重新计时、计数并使用当次选定参数。
- 如果先前超时或取消了同一任务链创建的研究，合法续查仅解除其取消标记，保留研究终态与全部旧结果。旧执行作用域仍不能写回，其他对话的研究不会解锁。

## 验收结果

- `python -m pytest -q`：**447 passed, 1 skipped**。跳过项仍为 Windows 符号链接权限；既有 Starlette 测试客户端弃用提示不影响结果。
- 配置/API/快照回归：默认值、完整覆盖、非法输入、默认持久化、续查预算重置、旧数据兼容和受控恢复。
- 执行回归：4,096 至 65,536 的上下界；DeepSeek、OpenAI、Qwen 与 Anthropic 协议初次/重试均不超额度；非 DeepSeek 报告也能恢复至调高的上限；2 次与 10 次决策实际生效；深度报告继承较短或较长的整轮截止。
- 超时回归：独立本地 HTTP 模型持续输出空白字节，避免将 read timeout 误当成整轮截止。真实 worker 在冻结截止后 1.5 秒测试阈值内退出，已完成结果可继续。另测旧轮回调隔离、持久化临时失败重试与完成后撤销计时器。
- 浏览器隔离验收：真实操作滑条选择 8,192 tokens / 2 分钟 / 4 次，发送请求携带完整预算；运行中控件禁用。暂停后改为 4,096 tokens 并发送新轮成功，实际模拟请求未超额度。
- 保存默认后刷新保持；设置页恢复 49,152 / 15 / 8。模拟保存 HTTP 503 后明确报错，原默认不变，重试成功。合法的非步长 API 值 8,193 在运行状态中如实显示。
- TypeScript 检查及 Vite 构建通过。桌面与 390×844 窄屏验收无横向溢出；窄屏展开内容可滚动且保留输入区，浏览器控制台无错误。

所有模型执行验收均使用隔离工作区和本地模拟接口，未调用真实付费模型。测试截图、请求记录和详细过程位于 Git 忽略的 `tmp/budget-ui-qa-20261014/`。
